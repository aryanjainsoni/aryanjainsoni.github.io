## What I learned

- A commit only shows up as a **green dot** if its email is linked to my GitHub account.
  The noreply email keeps my real email private and still counts.
- The basic Git loop: `git add` → `git commit -m "..."` → `git push`.
- **GitHub Actions** can build and deploy a site automatically on every push.
